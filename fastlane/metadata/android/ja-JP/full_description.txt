NativeCode は、Android のスマートフォンやタブレットを持ち運べる Linux ワークステーションに変えます。PC も root も不要です。

- PRoot 上の Alpaquita Linux：glibc ユーザーランド、apk パッケージマネージャー、Bash、Node.js、Python、GCC、Git。
- タブと追加キー列を備えたターミナル。
- Termux:X11 経由で画面に表示する Linux デスクトップ (Phosh)。端末が対応していれば Mesa PanVK (Mali) または Turnip (Adreno) で GPU アクセラレーション。
- チャット画面またはターミナルで使える AI コーディングエージェント: opencode と Codex (オープンソース)、および Claude Code、Antigravity、Grok、Kiro (プロプライエタリ、ダウンロードするルートファイルシステムに事前インストール済み)。
- プロジェクトツリー、差分表示、ブランチ切り替えを備えた Git ワークスペース。
- スマートフォンにログインするための SSH サーバー、リモートホストとキー。
- プロジェクトと設定のバックアップ。

すべて無料です。課金の壁、広告、解析、クラッシュレポートはなく、NativeCode 独自のサーバーも運用していません。アプリ内の任意のレポートは、選択した内容だけを送信します。

ダウンロード：Linux ルートファイルシステム (約 1.26 GB) とランタイム更新パック (約 317 MB) は、アプリ内で同意すると GitHub Releases から取得されます。その後、ご希望の場合のみ、Android SDK パック (約 69 MB) と GPU ドライバー (17～34 MB) が同じ方法で取得されます。各ファイルは固定されたサイズと SHA-256 で検証されます。Wi-Fi と約 10 GB の空き容量を推奨します。

アンチ機能: ダウンロードされるルートファイルシステムとアップデートパックには、プロプライエタリな AI コマンドラインツール (Claude Code、Antigravity、Grok、Kiro) が事前インストールされており、それぞれ提供元のライセンスに従います。これらが利用する AI サービスはプロプライエタリなネットワークサービスです。Android SDK パックには Google のライセンスに基づく Android SDK コンポーネントが含まれます。これらのダウンロードはアプリ自身のソースコードには含まれません。

arm64 端末の Android 8.0 以降が必要です。
