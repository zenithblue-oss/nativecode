يحوّل NativeCode هاتف أندرويد أو الجهاز اللوحي إلى محطة عمل لينكس محمولة. بلا حاسوب وبلا صلاحيات روت.

- Alpaquita Linux داخل PRoot: بيئة glibc مع مدير الحزم apk وBash وNode.js وPython وGCC وGit.
- طرفية بعلامات تبويب وصف مفاتيح إضافية.
- سطح مكتب لينكس (Phosh) على الشاشة عبر Termux:X11، مع تسريع GPU من Mesa PanVK (Mali) أو Turnip (Adreno) عندما يسمح الجهاز.
- وكلاء برمجة بالذكاء الاصطناعي في واجهة محادثة أو في الطرفية: opencode وCodex (مفتوحا المصدر)، إضافة إلى Claude Code وAntigravity وGrok وKiro (برمجيات مملوكة، مثبتة مسبقا في نظام الملفات الجذري الذي يتم تنزيله).
- مساحة عمل Git مع شجرة مشاريع وعرض للفروقات وتبديل الفروع.
- خادم SSH لتسجيل الدخول إلى الهاتف، إضافة إلى المضيفين البعيدين والمفاتيح.
- نسخ احتياطي لمشاريعك وإعداداتك.

كل شيء مجاني. لا جدار دفع ولا إعلانات ولا تحليلات ولا تقارير أعطال، ولا يشغّل NativeCode خوادم خاصة به. التقرير الاختياري داخل التطبيق يرسل فقط ما تختاره.

التنزيلات: يُنزَّل نظام ملفات لينكس الجذري (نحو 1.26 غيغابايت) وحزمة تحديث بيئة التشغيل (نحو 317 ميغابايت) من GitHub Releases بعد موافقتك داخل التطبيق. لاحقًا، وعند طلبك فقط، تُنزَّل بالطريقة نفسها حزمة Android SDK (نحو 69 ميغابايت) وتعريف GPU (من 17 إلى 34 ميغابايت). يُفحص كل ملف وفق حجم ثابت وSHA-256. يُنصح باستخدام Wi-Fi ومساحة فارغة نحو 10 غيغابايت.

الميزات غير المرغوبة: يتضمن نظام الملفات الجذري وحزمة التحديث اللذان يتم تنزيلهما أدوات سطر أوامر مملوكة للذكاء الاصطناعي مثبتة مسبقا (Claude Code وAntigravity وGrok وKiro)، ولكل منها ترخيص الجهة المصنِّعة، وخدمات الذكاء الاصطناعي التي تستخدمها هي خدمات شبكية مملوكة. تحتوي حزمة Android SDK على مكوّنات Android SDK من Google بموجب ترخيص Google. هذه التنزيلات ليست جزءا من الشيفرة المصدرية الخاصة بالتطبيق.

يتطلب أندرويد 8.0 أو أحدث على جهاز arm64.
