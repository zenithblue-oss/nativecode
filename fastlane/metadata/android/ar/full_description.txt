يحوّل NativeCode هاتفك أو جهازك اللوحي إلى محطة عمل Linux محمولة وبيئة تطوير بالذكاء الاصطناعي — دون الحاجة إلى حاسوب.

أبرز الميزات:

- حاوية Alpaquita Linux — بيئة مستخدم glibc أصلية مع apk وبيئة تطوير كاملة
- وضعا عزل — PRoot (دون root، موصى به) وChroot (على مستوى kernel، للأجهزة المرووتة)
- واجهة سطح مكتب XFCE4 — خادم عرض Termux-X11 مدمج مع تسريع GPU عبر VirGL
- محرك AI CLI — شغّل Claude Code وCodex وOpenCode وAgy وGrok وQwen وKiro في terminal الأصلي
- متجر البرامج — تصفح وثبّت حزمًا منتقاة من كتالوج داخل التطبيق
- مساحة عمل Git — شجرة مشاريع متعددة المستودعات، وحالة فورية، ومستعرض diff مرئي، وتبديل الفروع، وتكامل مع GitHub CLI
- بيئات تشغيل مُعدّة مسبقًا — Node.js 26 LTS وPython 3.12 وGCC ومديرو الحزم القياسيون
- تجهيز أدوات CLI — تثبيت موجَّه وإدارة بيانات الاعتماد لأدوات مزوّدي الذكاء الاصطناعي

يرشدك معالج الإعداد الأولي خلال التهيئة لأول مرة: فحص الجهاز وتثبيت بيئة Alpaquita PRoot بدون root بنقرة واحدة مع تقدم مباشر.

حوّل هاتفك أو جهازك اللوحي إلى محطة عمل Linux وذكاء اصطناعي محمولة للبرمجة وتطوير البرمجيات.
