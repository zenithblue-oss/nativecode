NativeCode превращает ваш телефон или планшет в портативную рабочую станцию Linux и среду разработки с ИИ — компьютер не нужен.

Ключевые возможности:

- Контейнер Alpaquita Linux — нативная среда glibc с apk и полной средой разработки
- Два режима изоляции — PRoot (root не нужен, рекомендуется) и Chroot (на уровне ядра, для устройств с root)
- Графический рабочий стол XFCE4 — встроенный сервер отображения Termux-X11 с ускорением GPU через VirGL
- ИИ CLI-движок — запускайте Claude Code, Codex, OpenCode, Agy, Grok, Qwen и Kiro в нативном terminal
- Маркетплейс ПО — просматривайте и устанавливайте подобранные пакеты из каталога в приложении
- Рабочая область Git — дерево проектов из нескольких репозиториев, статус в реальном времени, визуальный просмотр diff, переключение веток, интеграция с GitHub CLI
- Готовые среды выполнения — Node.js 26 LTS, Python 3.12, GCC и стандартные менеджеры пакетов
- Настройка CLI — пошаговая установка и управление учётными данными инструментов ИИ-поставщиков

Мастер приветствия проведёт через первую настройку: проверка устройства и установка среды Alpaquita PRoot без root одним касанием с показом хода выполнения.

Превратите телефон или планшет в портативную рабочую станцию Linux и ИИ для программирования и разработки ПО.
