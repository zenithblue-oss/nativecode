NativeCode trasforma un telefono o tablet Android in una workstation Linux portatile. Senza PC e senza root.

- Alpaquita Linux in PRoot: ambiente glibc con il gestore di pacchetti apk, Bash, Node.js, Python, GCC e Git.
- Terminale con schede e una riga di tasti aggiuntivi.
- Desktop Linux (Phosh) a schermo tramite Termux:X11, con accelerazione GPU di Mesa PanVK (Mali) o Turnip (Adreno) dove il dispositivo lo consente.
- Agenti di programmazione IA in una vista chat o nel terminale: opencode e Codex (open source), più Claude Code, Antigravity, Grok e Kiro (proprietari, preinstallati nel file system radice scaricato).
- Area di lavoro Git con albero dei progetti, vista delle differenze e cambio di branch.
- Server SSH per accedere al telefono, più host remoti e chiavi.
- Backup di progetti e impostazioni.

Tutto è gratuito. Nessun paywall, pubblicità, analisi o segnalazione di arresti anomali, e NativeCode non gestisce server propri. La segnalazione facoltativa nell'app invia solo ciò che scegli.

Download: il file system root di Linux (circa 1,26 GB) e un pacchetto di aggiornamento del runtime (circa 317 MB) vengono scaricati da GitHub Releases dopo il tuo consenso nell'app. In seguito, e solo se lo chiedi, vengono scaricati allo stesso modo il pacchetto Android SDK (circa 69 MB) e un driver GPU (da 17 a 34 MB). Ogni file è verificato con dimensione e SHA-256 prestabiliti. Consigliati Wi-Fi e circa 10 GB liberi.

Anti-funzionalità: il file system radice e il pacchetto di aggiornamento scaricati includono strumenti IA da riga di comando proprietari preinstallati (Claude Code, Antigravity, Grok, Kiro), ciascuno con la licenza del proprio produttore; i servizi IA che usano sono servizi di rete proprietari. Il pacchetto Android SDK contiene componenti dell'Android SDK di Google con la licenza di Google. Questi download non fanno parte del codice sorgente dell'app.

Richiede Android 8.0 o successivo su un dispositivo arm64.
