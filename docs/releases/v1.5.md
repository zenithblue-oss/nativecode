# NativeCode 1.5 — release notes

Release date: 2026-08-24
Version code: 6

## Highlights

- Bash is now the Debian runtime/bootstrap ABI. zsh remains optional interactive UX selected through a validated preference marker.
- PRoot, Chroot and PRoot-fast execution paths use the same Bash-safe automation and interactive fallback policy.
- Rooted Chroot sessions now cover terminal, AI CLI provisioning/launch, repairs, Software Manager and XFCE4.
- Workspace commands preserve the project’s isolation backend and safely pass paths containing spaces, quotes and shell metacharacters.
- Git Diff and repository operations use path-scoped `safe.directory` handling for Android-owned workspace trees.
- XFCE4 startup reuses live X11/GPU services and avoids START-side process kills or SELinux weakening.
- Upgrade migration keeps existing zsh preferences while restoring Bash runtime shells where older installs changed `/etc/passwd`.
